## Implementation contract

Use one shared CSS timing/easing scale. Keep hero content readable from first paint. Use CSS scene stacks for interruptible preview changes, reserving intrinsic space for existing examples rather than imposing fixed text heights. Inactive scenes must be inert and hidden from assistive technology, with no duplicate active IDs. Native FAQ disclosure remains usable without animation JS. One-shot group reveals are progressive enhancement: no pending hidden class or replay on small scroll changes. Pointer hover motion is gated; reduced motion resolves immediately. No auto carousel, simulated evaluation, score counting, scroll hijacking or new brand assets.

P0: hero, CTA, question carousel and sample retry. P1: learning loop, audience, pricing, FAQ, closing CTA. Validate these before extending quiet group reveals to P2 public pages. P3 only adds functional selected-state and real-result feedback, never broad authenticated page entrances.

## Delivered behavior

| Area | Purpose and treatment |
| --- | --- |
| Shared system | CSS timing/easing/elevation tokens; native CSS + small Web Animations bridge. No new dependencies. |
| Hero | Two headline groups, supporting copy and CTA enter once over <=820ms; initial opacity .65 rather than hidden text. Static, low-contrast voice motif; removed on small screens. |
| Question preview | Directional 16px transition; active-segment indicator follows deliberate navigation. Intrinsic scene stack prevents content-height jumps. No automatic advance. |
| Answer preview | Existing first/retry transcript and feedback crossfade. Inactive scenes inert and aria-hidden; active IDs unique. Retry action restores focus to the corresponding visible control. |
| Learning loop | One-shot 90ms group staggering and thin static connector, small fine-pointer row feedback. |
| Audience | Selected side indicator and reserved-height notebook/content transition; keyboard navigation immediate. |
| Plans | Coordinated card arrival, restrained fine-pointer lift; billing selection fades the actual price, without counting or changing prices/trial terms. |
| FAQ | Native details fallback, cancellable measured-height reveal/close, accurate expanded/region semantics. Rapid reversals and keyboard instant state supported. |
| Closing CTA/footer | One-shot heading arrival, focus/press/hover feedback and restrained static line detail. |
| About/audience pages | Quiet single-use group reveals; no repeated reading animations. |
| Resources/blog/tools | Category panel feedback on pointer selection; shared arrow/Home/End tab navigation, named panels and localized empty state. Typing does not trigger panel animation. |
| Auth | Brief form arrival finishes immediately when focused; quiet field transitions and live error/status semantics. Auth submission/consent/provider logic unchanged. |
| Application | Brief account-menu and genuine report-score-row appearance; shared selected-control feedback and actual mic-state color. No broad page entrance, animated scores, timer or assessment changes. |

One-shot observations stop after entry; animation cleanup cancels on route changes. Reduced-motion or a hidden document finishes active JS animations. Focusing an entering form/panel resolves its movement. Fine-pointer hover effects are gated by hover/pointer media queries. SSR content is visible without observers, native FAQ remains usable without JS, and decorative SVG is excluded from accessibility APIs.

## Deliberately omitted

Continuous decorative waveform/pulsing, auto-advancing examples, score count-ups, simulated live evaluation, floating blobs, large blur/glow effects, parallax, scroll hijacking, blanket authenticated-page entrances and per-frame React animation. These would distract from practice, misrepresent state, or add unnecessary work.
